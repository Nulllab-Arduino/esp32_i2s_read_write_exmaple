# ESP32 I2S 音频回环（Echo）示例程序

这是一个基于 Arduino 框架的 ESP32/ESP32-S3 示例程序，演示了如何通过 I2S 接口实现音频采集与播放（音频回环/回声测试）。

## 硬件要求

- **主控芯片**：ESP32 或 ESP32-S3
- **麦克风**：ZTS6631 或 INMP441（I2S 接口）
- **功放芯片**：NS4168
- **扬声器**：连接至功放输出端

## 硬件连接说明

### 扬声器 / 功放 (NS4168) - I2S 发送端 (TX, I2S0)

| 信号名称 | ESP32 引脚 | ESP32-S3 引脚 | 常见模块丝印 |
| :--- | :--- | :--- | :--- |
| BCLK | GPIO27 | GPIO4 | BCK / BCL |
| WS | GPIO26 | GPIO5 | LRCK / LRC / LRCLK |
| DOUT | GPIO25 | GPIO6 | DAT / DATA / DIN |

> 注：本示例未使用 MCLK，无需接线。

### 麦克风 (ZTS6631 / INMP441) - I2S 接收端 (RX, I2S1)

| 信号名称 | ESP32 引脚 | ESP32-S3 引脚 | 常见模块丝印 |
| :--- | :--- | :--- | :--- |
| BCLK | GPIO23 | GPIO40 | BCK / BCL |
| WS | GPIO32 | GPIO41 | LRCK / LRC / LRCLK |
| DIN | GPIO33 | GPIO42 | DAT / DATA / DOUT |

> 注：本示例未使用 MCLK，无需接线。

### ⚠️ 重要注意事项

#### 1. 声学反馈（啸叫）

**请务必让麦克风远离扬声器。**
如果麦克风距离扬声器过近，麦克风会拾取喇叭播放的声音，形成**正反馈回路（声学反馈）**。这会导致产生非常刺耳、高频的**啸叫声（Howling）**，严重影响体验甚至可能损坏硬件。
为了避免这种情况，请确保麦克风与扬声器之间有足够的距离，或者适当降低喇叭音量。

#### 2. 供电要求

**请务必使用外部独立电源供电（推荐 5V @ 1A 以上）。**
不要仅依赖电脑 USB 口供电。NS4168 功放在大音量工作时电流消耗较大，如果仅靠电脑 USB 供电，可能会因为**供电不足导致电压跌落**，进而引发 ESP32 **异常重启、死机或 I2S 音频传输错误**。
如果在测试过程中遇到设备频繁重启的情况，请优先检查供电是否稳定。

## 软件环境要求

- **IDE**：Arduino IDE
- **开发板包**：`esp32 by Espressif Systems` (版本 >= 3.3.10-cn 或 >= 3.3.10)
- **依赖库**：`cyfney-cpp`（在 Arduino 库管理器中搜索并安装）

## 配置与烧录步骤

1. 安装 [Arduino IDE](https://www.arduino.cc/en/software)。
2. 添加 ESP32 开发板支持：
   - 打开 `工具` -> `开发板` -> `开发板管理器`，搜索 `esp32`，安装 `esp32 by Espressif Systems`（确保版本 >= 3.3.10）。
3. 安装依赖库：
   - 打开 `项目` -> `加载库` -> `管理库...`
   - 搜索 `cyfney-cpp` 并安装。
4. 在 `工具` -> `开发板` 中选择对应型号：
   - ESP32 选择 `ESP32 Dev Module`
   - ESP32-S3 选择 `ESP32S3 Dev Module`
5. 编译并将程序上传到设备。

## 运行现象

- 设备开机后，首先会通过喇叭播报一段 **"Hello World"** 的音频提示音。
- 随后，设备会持续从麦克风采集声音，并立即从喇叭端播放出来，形成**音频回环测试（echo）**。
- 你可以对着麦克风说话，声音会带有轻微延迟地从喇叭中回放出来。

## 代码说明

- 使用了 ESP-IDF 的新版 I2S 驱动（`driver/i2s_std.h`）。
- 发送端（扬声器）：16位数据位宽，16kHz 采样率，单声道（Slot Mask 设置为 BOTH）。
- 接收端（麦克风）：32位数据位宽，16kHz 采样率，单声道（Slot Mask 设置为 LEFT）。
- 在 `loop()` 中每次读取 20ms 的音频数据，将麦克风采集的 32 位数据截取处理为 16 位样本，并写入 I2S 发送端进行播放。

### 📝 位操作与增益调整

在 `loop()` 函数中，你会注意到这一行代码：

```cpp
int32_t sample = raw_32bit_samples[i] >> 14;
```

**为什么是右移 14 位而不是 16 位？**

- MEMS 麦克风（ZTS6631/INMP441）输出的是 **24 位有效音频数据**，在 I2S 协议中左对齐封装在 32 位帧中，低 8 位为无效填充 0。因此首先需要右移 8 位丢弃填充位，得到真实的 24 位音频数据。
- 要将 24 位数据转换为 I2S 发送端支持的 16 位格式，常规做法是再右移 8 位（总共移位 16 次），将信号缩放到 16 位有符号整数范围（-32768 ~ 32767）。
- 但 MEMS 麦克风本身的模拟灵敏度较低，而 NS4168 功放需要较高的输入电平才能推动扬声器发出足够响度的声音。这里仅右移 14 位而非 16 位，相当于比标准转换少移了 2 位，等效为信号增加了 **4 倍增益（2^(16-14) = 4）**，属于故意的软件放大，用于弥补麦克风灵敏度不足的问题。

**如何调整回声大小：**

- **减小数值（如改为 12、13）**：移位次数更少，增益更高（16 倍、8 倍），回声会明显变大，但极易出现削波（Clipping）和失真。
- **增大数值（如改为 15、16）**：移位次数更多，增益更低（2 倍、1 倍），回声会变小；其中 16 是标准无增益转换值，信号无放大也无衰减。

你可以根据实际使用的麦克风灵敏度和喇叭音量，微调这个数值以获得最佳效果。
